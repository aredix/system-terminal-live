# System Terminal Live

**System Terminal Live** est un projet open source dont l'objectif et les fonctionnalités sont à présenter autour de ses deux composants principaux : `companion` et `workshop`.

## ⚙️ Installation

- Lancer Wallpaper Engine
- Executer companion/Demarrer.cmd

## 📁 Structure du projet

Le dépôt est organisé autour de deux répertoires :

- **companion** : composant Companion du projet.
- **workshop** : composant Workshop du projet.

## 🚀 Objectifs

Ce projet vise à proposer une solution organisée autour de ses différents composants, avec une architecture modulaire permettant de séparer leurs responsabilités.
